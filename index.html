    Expected columns

    One row per employee per month. Column order does not matter and common header spellings are accepted (e.g. Location, Hub or Branch all work).

    Required
    • Employee ID
    • Employee Name
    • Department
    • Location / Hub
    • Month
    • Monthly Target
    • Actual Handled
    • SLA %
    • Accuracy %
    Optional
    • Working Days
    • Present Days
    • Attendance % (else from days, else 100)
    • Target Achievement % (else actual ÷ target)
    • Average TAT (hrs)
    • Error / Rework Count
    • Overtime Hours

    Month accepts Sep 2026, 2026-09, 09/2026 or a full date. The Performance Index is recalculated with the published weights. Nothing is uploaded anywhere — the file is read in your browser.
